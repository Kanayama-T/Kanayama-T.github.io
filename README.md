# 有限会社丸富 コーポレートサイト（制作中）

WordPressで公開中の企業サイトを、HTML・CSS・JavaScriptのみで作り直した静的サイトです。外部ライブラリは不要です。公開ページのHTMLは `scripts/prerender.mjs` で生成します。

GitHub Pages への公開と独自ドメインへの切り替えは [DEPLOY.md](DEPLOY.md) を参照してください。

## ローカル確認

```bash
cd /mnt/c/Users/Kanayama/source/spe_app_marutomi_hp
python3 -m http.server 8000
```

ブラウザーで `http://localhost:8000/` を開きます。`file://` ではなくHTTPで確認してください。

本文やデザインを編集した後は `node scripts/prerender.mjs` を実行して、各ページのHTMLを更新してください。非公開のテストページは生成対象に含めていません。

## 公開前に確認すること

1. 写真・文章・会社情報・募集条件の最新性と掲載許可。
2. 問い合わせ・応募フォームの送信先。項目は再現していますが、送信機能は未設定です。現在の新サイトでの連絡手段は電話と、現行サイトで案内されているLINEです。フォームの送信機能を使う場合は、公開前に送信先を設定してください。
3. 許可証の有効期限。現行サイトに掲載されているPDFをコピーしていますが、公開前に最新の許可証と照合してください。
4. プライバシーポリシー。現行サイトの本文を取り込んでいますが、新しい運用に合わせた確認が必要です。
5. お知らせ記事と旧URLの転送先。古いWordPressページからのリンク切れを確認します。

公開切り替えは、これらを確認してから行います。

## 素材

`assets/` のロゴ・写真・アイコンは、既存の `https://marutomi-t.co.jp/` の公開ページと、受け取った画像ZIPから取得したものです。収集運搬ページの車両・コンテナ写真、中間処理ページの現場写真、対応地域の画像などを配置しています。元のWordPressでは車両一覧の大半が同じ代用画像です。

受け取った資料から、現在有効なテーマは **BusinessPress Child** と確認済みです。公開されている子テーマの `style.css` はテーマ情報のみで、独自の見た目は主に「追加CSS」に記述されています。XML・画像ZIP・追加CSS・テーマ画面を確認済みです。ログイン情報や `wp-config.php` は不要です。
